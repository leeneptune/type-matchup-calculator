# Pokémon Type Matchup Calculator

A Python-based Pokémon type matchup calculator that determines strengths, weaknesses, resistances, and immunities using Pokémon typing data and a custom battle type chart.

---

# Features

* Lookup Pokémon by name
* Automatically retrieves Pokémon typing from the Pokédex
* Calculates:

  * Super effective matchups
  * Not very effective matchups
  * Immunities
  * Defensive weaknesses
  * Defensive resistances
* Uses JSON-based data architecture
* Easy to extend with additional Pokémon or generations
